# Mind Palace modpack

Minecraft 26.3 + Fabric, with Mind Palace (Locus blocks that open Obsidian notes), Fabric API, and Sodium.
Mods auto-update every time you hit Play.

## Install (Prism Launcher)

1. In Prism: **Add Instance → Import**, and paste:
   ```
   https://github.com/litsush/modpack0/releases/latest/download/MindPalace-prism.zip
   ```
2. Hit **Play**. A small window downloads/updates the mods, then the game starts.
3. Set your Obsidian vault name in `config/mindpalace.properties` (created on first launch; defaults to `Main`).
   A Locus opens the note with its name *in your vault* — so you need the same notes for them to open.

## Updating

Nothing to do — the pre-launch step syncs the mods from this repo each launch.
